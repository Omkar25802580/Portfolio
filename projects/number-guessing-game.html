Number Guessing Game (Java)

A console game where the computer picks a secret number and gives "too high" or "too low" hints until you guess it. I built it to practice Java fundamentals like random numbers, loops, and conditionals.

Overview

What this project is

The program picks a random number from 1 to 100 and keeps asking for guesses. After each guess it says whether you were too low or too high, and it counts how many attempts you needed.

There is a nice link to my DSA project too: if you always guess the middle of the remaining range, you are doing binary search, and you can find any number from 1 to 100 in at most 7 guesses.

Source code

The full program

This runs in a terminal, not a browser, so the code below is the whole project.

GuessingGame.java

Java
import java.util.Random;
import java.util.Scanner;

public class GuessingGame {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        Random rand = new Random();

        int secret = rand.nextInt(100) + 1;   // 1 to 100
        int attempts = 0;
        int guess;

        System.out.println("Guess the number between 1 and 100!");

        do {
            System.out.print("Your guess: ");
            guess = sc.nextInt();
            attempts++;

            if (guess < secret) {
                System.out.println("Too low!");
            } else if (guess > secret) {
                System.out.println("Too high!");
            } else {
                System.out.println("Correct! You got it in " + attempts + " attempts.");
            }
        } while (guess != secret);

        sc.close();
    }
}

How it works

Three steps

01

Pick a secret number

Random.nextInt(100) + 1 gives a number between 1 and 100 each time the game starts.

02

Loop until correct

A do-while loop always asks at least once, and repeats until the guess matches.

03

Give feedback

An if / else if / else chain prints the hint, and a counter tracks the attempts.
